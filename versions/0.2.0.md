# @meng-xi/unix-utils v0.2.0 发布：modal 模块来了

**发布日期**：2026-10-11

unix-utils 第二个版本正式发布！继 toast 模块之后，新增 **modal 模块**——对 `uni.showModal` 的全端兼容封装，覆盖 Android / iOS / Web / 微信 / 鸿蒙五端，参数与 `uni.showModal` 完全同构，迁移零成本。

## 为什么需要它

`uni.showModal` 官方各端能力差异同样长期存在：按钮颜色部分端不生效、默认色不一致、小程序端按钮文案 4 字符上限静默截断、返回值 `cancel` 字段可能缺失、`editable` 支持参差。unix-utils 用一套与 `uni.showModal` 完全同构的 API 抹平这些差异——返回值字段恒定互斥、颜色归一化生效保障、不支持参数自动降级并经 `fail` 回调留痕，降级可感知、可过滤。

## 核心特性

- **参数完全对齐**：`title / content / showCancel / cancelText / cancelColor / confirmText / confirmColor / editable / placeholderText / success / fail / complete` 与 `uni.showModal` 同构；除回调外均为可选字段
- **分端混合通道**（自动分发，业务零配置）：
  - App / 微信 / 鸿蒙：`uni.showModal` 原生通道（真机实测颜色全生效）+ 库内归一化
  - Web：DOM 单例自绘，蒙层点击不关闭、`editable` 真实渲染输入框
- **返回值恒定**：`ModalResult` 的 `confirm` / `cancel` 恒存在且互斥（消除各端 `cancel` 字段缺失差异），`editable` 场景 `content` 携带用户输入
- **颜色归一化**：校验 `#RGB` / `#RRGGBB` / `#RRGGBBAA`，非法值降级平台默认色并留痕；App 原生通道不支持 alpha 时自动剥离并留痕；库内默认确认色 `#007aff` / 取消色 `#000000`
- **受限端文案截断**：微信 / 鸿蒙端按钮文案超 4 字符库内自动截断，App / Web 端完整显示
- **Promise 式 `showModalAsync`**：resolve `ModalResult`，点取消不算失败（与 uni 语义一致）；失败 reject `ModalFail` 结构的 JSON 字符串（全端统一，业务侧 `JSON.parse<ModalFail>(err as string)` 还原）
- **快捷 API `showModalAlert`**：单确定按钮 alert 语义
- **全局默认配置 `configureModal`**：项目级预设按钮文案与颜色，字段传 `null` 沿用库内置默认 / 平台默认
- **结构化失败信息 `ModalFail`**：`errCode`（1001 参数非法 / 2001 平台不支持且已降级）、`errSubject`、`param`、`platform`，类型已对外导出

## 快速开始

```typescript
// uni_modules 方式导入（npm 方式改为 '@meng-xi/unix-utils'）
import { showModal, showModalAlert } from '@/uni_modules/unix-utils'

// 基础用法——与 uni.showModal 参数完全一致
showModal({
  title: '删除确认',
  content: '删除后不可恢复，是否继续？',
  confirmColor: '#ff0000',
  success: (res) => {
    if (res.confirm) doDelete()
  }
})

// Promise 式——点取消不算失败
import { showModalAsync } from '@/uni_modules/unix-utils'

const res = await showModalAsync({ title: '保存修改', content: '是否保存当前修改？' })
if (res.confirm) save()

// alert 语义 + 全局默认
import { configureModal } from '@/uni_modules/unix-utils'

configureModal({ confirmText: '知道了', confirmColor: '#00aa00' })
showModalAlert('提示', '操作已完成')
```
